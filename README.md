# Кадры инструкций Mops VPN

Картинки для статей на telegra.ph. Собираются из тех же экранов, что и PDF,
скриптом `build_article_images.py`, поэтому кадр в статье и кадр в файле
совпадают. Правки вносятся в инструкции, а не здесь.

Папка — устройство и клиент, файл — шаг. Прямая ссылка на кадр:

    https://raw.githubusercontent.com/exemble404/mops-vpn-guide/main/<папка>/<шаг>.jpg

Всего кадров: 84.
